# Recursive forecast comparison outputs

[results.json](results.json) records latest-origin and held-out comparisons,
settings, source hashes, forecast diagnostics, scores, runtime and Monte Carlo
intervals. The NPZ files retain scenario arrays; audit JSON files retain the
per-path recalibrations behind each mode. See the [experiment guide](../readme.md)
and [validator](../validate_recursive.py) for exact reproduction and interpretation.
