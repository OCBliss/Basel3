# PDF

This folder contains supporting research documentation that accompany the Basel III
research platform. It provide the theoretical and mathematical
motivation for several modules within the repository and are intended as
supplementary reading. ***They are not required to understand or execute the
pipeline.***

## Included Documents

### Recursive Multifactor Interest-Rate Framework

This document presents a proposed mathematical framework for recursively
updating interest-rate model parameters. It provides the theoretical foundation
for the duration-sensitive RWA module and describes the proposed recursive
parameter estimation framework.

The framework is currently under active development. The accompanying RWA
module implements portions of this research, while empirical calibration and
full production implementation remain ongoing.
